# 学生综合素质评价系统 - 操作手册

## 系统概述

本系统基于大数据分析技术，运用K-means聚类算法，从品德发展、学业发展、体能发展、艺术素养、实践创新五个维度对学生综合素质进行全面评价。

## 角色说明

系统包含四种角色，各角色可见菜单和功能不同：

- 管理员：系统管理（用户、班级、学生、通知、日志）+ 评价管理 + 聚类分析 + 数据看板
- 教师：班级管理 + 学生管理 + 评价管理 + 聚类分析 + 数据看板
- 学生：我的评价 + 数据看板 + 系统通知
- 家长：孩子评价 + 数据看板 + 系统通知

## 功能操作说明

### 1. 登录与快捷登录

- 在登录页输入用户名和密码登录
- 点击底部"快捷登录"按钮可一键登录对应角色的演示账号
- 支持用户注册，注册时选择角色

### 2. 数据看板

- 展示学生总数、教师总数、班级总数、评价记录数等统计信息
- 雷达图展示各维度平均得分
- 饼图展示学生聚类分布
- 柱状图展示综合成绩分布

### 3. 评价管理（管理员/教师）

五个维度的评价录入页面操作方式一致：
1. 点击"录入评价"按钮
2. 选择学生和学期
3. 填写各项评分
4. 点击确定保存

支持按学期和学生筛选查询。

### 4. 综合素质评价

- 汇总展示学生五个维度的综合评价数据
- 支持按聚类类别筛选
- 点击"详情"查看学生雷达图和个性化建议
- 点击"成长轨迹"查看学生各学期的发展趋势折线图

### 5. 聚类分析（管理员/教师）

1. 选择学期和聚类数量（默认5类）
2. 点击"执行聚类分析"
3. 系统自动汇总各维度数据，执行K-means聚类
4. 展示轮廓系数、各聚类特征、分布饼图和雷达对比图
5. 自动为每个学生生成个性化发展建议

### 6. 学生端 - 我的评价

- 查看最新学期的综合素质评价详情
- 雷达图直观展示各维度表现
- 查看个性化发展建议
- 成长轨迹图展示历史发展趋势

### 7. 家长端 - 孩子评价

- 查看关联孩子的综合素质评价
- 支持多个孩子切换查看
- 功能与学生端类似

### 8. 系统管理（管理员）

- 用户管理：增删改查用户，重置密码，启用/禁用
- 班级管理：管理班级信息，分配班主任
- 学生管理：管理学生信息，关联用户和班级
- 通知管理：发布和管理系统通知
- 操作日志：查看系统操作记录
