# 学生综合素质评价系统 - Windows部署手册

## 环境要求

- JDK 1.8+
- Node.js 16+
- MySQL 8.0
- Maven 3.6+

## 一、数据库部署

1. 确保MySQL服务已启动
2. 打开命令行，进入项目根目录，执行以下命令初始化数据库：

```bash
mysql -u root -proot --default-character-set=utf8mb4 < sql/init.sql
mysql -u root -proot --default-character-set=utf8mb4 < sql/demo-data.sql
mysql -u root -proot --default-character-set=utf8mb4 < sql/demo-evaluation-data.sql
```

如果mysql不在PATH中，使用完整路径，例如：
```bash
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -proot --default-character-set=utf8mb4 < sql/init.sql
```

## 二、后端部署

1. 进入backend目录：
```bash
cd backend
```

2. 如需修改数据库密码，编辑 `src/main/resources/application.yml` 中的 `spring.datasource.password`

3. 编译打包：
```bash
mvn clean package -DskipTests
```

4. 启动后端服务：
```bash
java -jar target/student-quality-evaluation-1.0.0.jar
```

后端默认端口：8089，如端口被占用，修改 `application.yml` 中的 `server.port`

## 三、前端部署

1. 进入frontend目录：
```bash
cd frontend
```

2. 安装依赖：
```bash
npm install
```

3. 开发模式启动：
```bash
npm run dev
```

前端默认端口：5180，如端口被占用，修改 `vite.config.js` 中的 `server.port`

4. 生产构建：
```bash
npm run build
```

构建产物在 `dist` 目录下，可部署到Nginx等Web服务器。

## 四、访问系统

浏览器打开：http://localhost:5180

## 六、常见问题

1. 端口被占用：修改对应配置文件中的端口号，不要杀掉其他进程
2. 数据库连接失败：检查MySQL服务是否启动，密码是否正确
3. 前端代理失败：确保后端服务已启动
